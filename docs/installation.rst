Installation
============

TSADmetrics can be installed via pip from PyPI.

.. code-block:: bash

   pip install tsadmetrics

When using ``uv`` to manage project dependencies, add TSADmetrics directly to
the project environment with:

.. code-block:: bash

   uv add tsadmetrics

Requirements
------------


- Python 3.8+
- numpy
- pandas
- PyYAML
