Installation
============

TSADmetrics is available on PyPI. If you manage your project with ``uv``, add
it as a dependency:

.. code-block:: bash

   uv add tsadmetrics

Alternatively, install it with ``pip`` in your Python environment:

.. code-block:: bash

   python -m pip install tsadmetrics

Requirements
------------


- Python 3.8+
- numpy
- pandas
- PyYAML
