Uninstallation
==============

To uninstall **TSADmetrics** from your Python environment, you can use `pip`:

.. code-block:: bash

   pip uninstall tsadmetrics

This command will remove the **TSADmetrics** package and all its files from your environment.  
If you want to ensure all dependencies installed specifically for TSADmetrics are removed, you may also uninstall them manually or use a virtual environment to isolate the installation.

Notes
-----

- If you installed TSADmetrics in a virtual environment, make sure the virtual environment is activated when running the uninstall command.
- Running `pip uninstall tsadmetrics` may prompt for confirmation; you can add `-y` to automatically confirm:

.. code-block:: bash

   pip uninstall -y tsadmetrics
